# Student CRUD - Spring Boot

A Student Management System developed using Java, Spring Boot, Spring Data JPA, and MySQL. This project demonstrates REST API development and database operations using CRUD functionality.

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- IntelliJ IDEA
- Git & GitHub

## ✨ Features

- Add a new student
- Retrieve all students
- Retrieve student by ID
- Update student details
- Delete student records
- Database integration using MySQL
- RESTful API architecture

## 📁 Project Structure

```text
src/main/java/
    in.strikes.crudSpringBootDemo/
        controller/
            StudentController.java
        entity/
            Student.java
        repository/
            StudentRepository.java
        service/
            StudentService.java
        CrudSpringBootDemoApplication.java

src/main/resources/
    application.properties
```

## ⚙️ Prerequisites

Make sure you have installed:

- Java JDK
- IntelliJ IDEA
- MySQL Server
- Maven

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/mch750018-byte/Student-CRUD-Spring-Boot.git
```

2. Open the project in IntelliJ IDEA.

3. Configure your MySQL database in `application.properties`.

4. Run the main Spring Boot application.

## 🛠️ Database Configuration

Configure your database URL, username, and password in:

`src/main/resources/application.properties`

Never upload real database passwords or credentials to GitHub.
